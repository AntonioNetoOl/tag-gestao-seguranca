# Visão Geral — Sistema TAG

## Objetivo

O sistema TAG será uma aplicação web para gestão operacional de uma empresa de segurança.

A aplicação substituirá controles feitos em planilhas, centralizando cadastros, eventos, escalas, pagamentos pendentes e relatórios.

## Usuários

Inicialmente, o sistema será usado apenas pela gestão da TAG.

Não haverá acesso para funcionários, clientes ou terceiros no MVP.

## Módulos do MVP

- Login
- Dashboard
- Cadastro de funcionários
- Cadastro de casas
- Cadastro de tipos de evento
- Cadastro de eventos
- Gestão de escala
- Exportação de escala em Excel
- Pagamentos pendentes
- Confirmação de pagamento
- Relatórios de escala

## Stack proposta

- Frontend: Angular
- Backend: ASP.NET Core
- Banco de dados: PostgreSQL
